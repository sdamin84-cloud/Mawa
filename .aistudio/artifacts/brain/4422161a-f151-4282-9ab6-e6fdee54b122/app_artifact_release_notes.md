## 🌟 নতুন যুক্ত হওয়া ফিচারসমূহ (Firebase Integration)

1. **গুগল ফায়ারবেস ক্লাউড ব্যাকআপ ও রিস্টোর (Google Cloud Firestore):**
   * **প্রোজেক্ট আইডি:** `gen-lang-client-0599894239`
   * **ডাটাবেজ আইডি:** `ai-studio-android-mawa-4422161a-f151-4282-9ab6-e6fdee54b122`
   * **গুগল সাইন-ইন:** Android Jetpack `CredentialManager` এবং `GoogleIdTokenCredential` দিয়ে এক ক্লিকে গুগল একাউন্টে সাইন-ইন।
   * **নিরাপত্তা রুলস:** ব্যবহারকারীর নিজস্ব ডাটা শুধু তার নিজের গুগল ইউজার আইডিতে (`request.auth.uid == userId`) প্রাইভেট ও সুরক্ষিত থাকে। `firestore.rules` সফলভাবে ফায়ারবেসে ডেপ্লয় করা হয়েছে।
   * **১-ক্লিক ব্যাকআপ ও রিস্টোর:** কাস্টমার, ট্রানজেকশন, পণ্য তালিকা, ক্যাশ খাতা ও দোকান সেটিংসের সম্পূর্ণ হিস্ট্রি ফায়ারবেস ক্লাউডে টাইমস্ট্যাম্প ও সামারিসহ সংরক্ষিত থাকে।

2. **ডুয়াল ক্লাউড সুবিধা (Dual-Cloud Support):**
   * ব্যবহারকারী গুগল ফায়ারবেস অথবা সুপাবেজ ক্লাউড—উভয় সুবিধাই পছন্দমতো ব্যবহার করতে পারবেন।
   * সাইড ড্রয়ার, মোর মেনু এবং ব্যাকআপ হাব থেকে সরাসরি গুগল ফায়ারবেস ডায়ালগ খোলা যাবে।

## 🗄️ মূল আর্কিটেকচার ও সুবিধাসমূহ

1. **দোকান ও ব্যক্তিগত হিসাব খাতা (Dual Mode Accounting):**
   * **দোকানের খাতা:** বাকি বিক্রি, নগদ বিক্রি, বাকি আদায়, পণ্য ক্রয়, দোকান খরচ এবং ফর্দ (শপিং লিস্ট)।
   * **ব্যক্তিগত খাতা:** পারিবারিক বাজার, চিকিৎসা, সন্তানের পড়াশোনা, ইউটিলিটি বিল ও নিজস্ব আয়ের পৃথক হিসাব।
   * **উভয় মোড (Both):** এক ট্যাপে দোকান ও পারিবারিক হিসাবের মধ্যে সুইচ করা যায়।

2. **স্মার্ট ক্যাশবাক্স ও দৈনিক হিসাব (Daily Cashbox Management):**
   * **সাবেক ক্যাশ (`sabekCash`):** দিনের শুরুতে ক্যাশবাক্সে থাকা আগের জমার হিসাব।
   * **সমাপনী ক্যাশ (`closingCash`):** দিনের শেষে ক্যাশবাক্সে গোনা নগদ টাকা।
   * **স্বয়ংক্রিয় ক্যাশ মেলা ও বেচা হিসাব:**  
     $$\text{নগদ বেচা} = \text{সমাপনী ক্যাশ} + \text{দিনের খরচ} - \text{সকালবেলার সাবেক ক্যাশ} - \text{বাকি আদায়}$$
   * **অক্ষত রাখার নিশ্চয়তা:** ক্লাউড ও লোকাল ডাটা মার্জিংয়ের সময় `sabekCash` ও `closingCash` কোনোটির মানই শূন্য দিয়ে ওভাররাইট হয় না।

3. **স্মার্ট ডিডুপ্লিকেশন ও জেসন মাস্টার ব্যাকআপ (Duplicate Prevention):**
   * **মাস্টার ব্যাকআপ আপডেট:** মোবাইলের ফাইলে প্রতিবার নতুন জেসন তৈরি না করে `mawa_master_backup.json` ফাইলে আপডেট হয়।
   * **ডাবল এন্ট্রি রোধ:** জেসন ফাইল আপলোড করে ক্লাউডে লগইন করলেও তারিখ, কাস্টমার, টাকার পরিমাণ এবং ট্রানজেকশন সিগনেচার মিলিয়ে ডুপ্লিকেট রোধ করা হয়।

## 🛡️ ফায়ারবেস সিকিউরিটি রুলস (firestore.rules)

```
rules_version = '2';

service cloud.firestore {
  match /databases/{database}/documents {
    // User-specific data: Users can only read and write their own documents
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```
